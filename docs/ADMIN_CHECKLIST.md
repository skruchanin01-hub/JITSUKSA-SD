# Admin Checklist รายสัปดาห์

## ก่อนกิจกรรม

1. เข้าเว็บ > Admin
2. Login
3. ตั้งค่า:
   - termKey
   - weekKey
   - sessionId
   - openAt
   - closeAt
4. กดเปิดระบบ
5. ทดสอบด้วยนักเรียน 1 เครื่อง
6. เปิด Dashboard ไว้ 1 เครื่อง

## ระหว่างกิจกรรม

- กด Refresh Dashboard หรือเปิด Auto refresh ทุก 60 วินาที
- อย่าเปิด Dashboard หลายเครื่องโดยไม่จำเป็น
- แจ้งนักเรียนให้รอจนขึ้น “บันทึกคะแนนสำเร็จแล้ว”

## หลังจบกิจกรรม 1 ชั่วโมง

1. กดปิดระบบ
2. Refresh Dashboard
3. Export CSV
4. เก็บไฟล์ CSV ลง Drive โรงเรียน

## สัปดาห์ถัดไป

1. เปลี่ยน weekKey เช่น W08
2. เปลี่ยน sessionId เช่น 2569-T1-W08
3. ตั้งเวลาเปิด-ปิดใหม่
4. กดเปิดระบบ
